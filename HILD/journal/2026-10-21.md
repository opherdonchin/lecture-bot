**Results:** The HILD script tests in `tests/hild/` pass (15 tests). One

**Findings:**

- HILD's installer cannot be used on an existing repository; the upstream
  draft PRs ([#11](https://github.com/Motor-Learning-Lab/HILD/pull/11),
  [#13](https://github.com/Motor-Learning-Lab/HILD/pull/13),
  [#14](https://github.com/Motor-Learning-Lab/HILD/pull/14)) were still open.
  PR #13's head is newer than PR #14's branch and contains PR #11.
- `pixi run sync-dev` rsyncs server `docs/` and `prompts/` into the
  repository with `--delete`, which conflicts with the repository being
  authoritative. It was not used for today's copy.
- Four identical PDF files with misleading extensions (`.aaa.html`, `.ini`,
  `.log`, `.pdf`), owned by root and dated 2026-10-20, sit in the server's
  `/srv`. They were reported to the researcher and not investigated further.

**Decisions:** An independent HILD build rather than an install
([decision 0001](../decisions/0001-independent-hild-build.md), proposed).
Pin HILD at `92de97e`. Enable Claude Code and Codex hooks, but not Copilot.
Keep `prompts/archive/` and `docs/archive/` as deliberate history.

**Permission points:** The `scope` and `understanding-debt` labels were
created just before scope #14 was approved, although the scope lists their
creation as a lifted stopping point. This was reported to the researcher.
