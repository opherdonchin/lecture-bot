# 2026-10-21

## Session 1 — Assessment and planning for the PML course; building lecture-bot's HILD process

**Goal:** Understand what lecture-bot needs in order to serve the
Probabilistic Machine Learning course alongside Statistics, and set up a
HILD process to carry out that work under review.

**Done:**

- Fast-forwarded local `main` to `origin/main`
  ([a1f195f](https://github.com/opherdonchin/lecture-bot/commit/a1f195f)), at the
  researcher's request.
- Read-only assessment of lecture-bot (pipeline, prompts, grading, admin),
  the production server (services, nginx paths, lecture folders, data) and
  the PML development repository (syllabus, L01 materials, AGENTS.md).
  Server `prompts/` and `docs/` are byte-identical to the repository.
- At the researcher's request, copied the Statistics runtime state from the
  server to the private folder `~/lecture-bot-instances/statistics/`
  (database, lectures 01–12, submissions, exports, logs, environment file),
  outside the clone and unreadable by other users.
- Prepared a planning page (private) with four proposed scopes. The
  researcher redirected the HILD adoption from an install to an independent
  build based on HILD.
- Created [scope #14](https://github.com/opherdonchin/lecture-bot/issues/14).
  The researcher approved it in chat after reviewing the issue, and the
  approval is [recorded on the issue](https://github.com/opherdonchin/lecture-bot/issues/14#issuecomment-6309726749).
- Opened draft [PR #15](https://github.com/opherdonchin/lecture-bot/pull/15):
  a verbatim copy of selected files from
  [HILD@92de97e](https://github.com/Motor-Learning-Lab/HILD/tree/92de97e84bd1c6b61f9e1c997765e361dc7cd458),
  then adaptations of the process, skills, tests, README, `AGENTS.md`, hooks,
  [provenance](../PROVENANCE.md), [plan](../plan.md) and proposed
  [decision 0001](../decisions/0001-independent-hild-build.md).

**Results:** The HILD script tests in `tests/hild/` pass (15 tests). One
upstream consistency test initially failed because the new skill table put
`` `hild-understood` `` in a table cell. The skill names became links to
their files, which the process also requires.

**Findings:**

- HILD's installer cannot be used on an existing repository; the upstream
  draft PRs ([#11](https://github.com/Motor-Learning-Lab/HILD/pull/11),
  [#13](https://github.com/Motor-Learning-Lab/HILD/pull/13),
  [#14](https://github.com/Motor-Learning-Lab/HILD/pull/14)) were still open.
  PR #13's head is newer than PR #14's branch and contains PR #11.
- `pixi run sync-dev` rsyncs server `docs/` and `prompts/` into the
  repository with `--delete`, which conflicts with the repository being
  authoritative. It was not used for today's copy.
- Four identical PDF files with misleading extensions (`.aaa.html`, `.ini`,
  `.log`, `.pdf`), owned by root and dated 2026-10-20, sit in the server's
  `/srv`. They were reported to the researcher and not investigated further.

**Decisions:** An independent HILD build rather than an install
([decision 0001](../decisions/0001-independent-hild-build.md), proposed).
Pin HILD at `92de97e`. Enable Claude Code and Codex hooks, but not Copilot.
Keep `prompts/archive/` and `docs/archive/` as deliberate history.

**Permission points:** The `scope` and `understanding-debt` labels were
created just before scope #14 was approved, although the scope lists their
creation as a lifted stopping point. This was reported to the researcher.

**Open questions / next:** The researcher reviews PR #15. After merge,
verify live skill and hook discovery, then propose Scopes 2 and 3 (see the
[plan](../plan.md)).
